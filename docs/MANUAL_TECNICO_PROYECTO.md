# 📖 Manual Técnico Integral: App Detector de Voz + Voicey AI

## 1. Visión General del Proyecto
**App Detector de Voz** es una solución de ingeniería de audio e inteligencia artificial en tiempo real. Integra captura de señales acústicas mediante la Web Audio API, análisis de decibelios (dB) en vivo, transcripción ultrarrápida impulsada por **Groq Whisper Large v3 Turbo**, persistencia histórica en **Supabase PostgreSQL** y un copiloto conversacional denominado **Voicey AI** que utiliza el protocolo **WebMCP** (Model Context Protocol vía Vercel AI SDK).

## 3. Arquitectura del Sistema y Flujo WebMCP

### 3.1 Flujo de Datos
1. **Entrada de Audio**:
   - Vía Micrófono en vivo: Hook `useAudioRecorder.ts` inicializa un `AudioContext` con `AnalyserNode` para medir la intensidad del volumen en dB.
   - Vía Subida de Archivo: Hook `useFileUploader.ts` permite subir archivos `.mp3`, `.wav`, `.m4a` o `.webm`.
2. **Procesamiento de Transcripción**:
   - El audio se empaqueta en `FormData` y se envía a `POST /api/transcribe`.
   - El backend invoca a `groq.audio.transcriptions.create` usando el modelo `whisper-large-v3-turbo`.
3. **Registro Automático**:
   - Tras obtener el texto, se ejecuta la Server Action `saveVoiceLogAction` (en `src/app/actions/save-voice-log.ts`), que valida el esquema con **Zod** y guarda duración, transcripción y nivel de dB en la tabla `voice_logs` de Supabase usando credenciales seguras de servidor.
4. **Interacción con Voicey AI (WebMCP)**:
   - El usuario abre el componente `VoiceyChat.tsx`.
   - Al preguntar sobre sus grabaciones, `POST /api/chat` invoca a Llama 3.3 junto con las herramientas (`tools.ts`).
   - El modelo decide llamar a `get_audio_stats` o `get_recent_logs`, ejecutando consultas SQL directas contra Supabase y devolviendo la respuesta contextualizada en lenguaje natural.

## 4. Estructura de la Base de Datos (Supabase)

### Tabla `voice_logs`
```sql
create table public.voice_logs (
    id bigint generated by default as identity primary key,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    duration numeric not null,
    transcript text not null,
    db_level integer default 50,
    label text default 'Grabación de voz'
);
```

## 5. Herramientas WebMCP Registradas (`src/app/api/chat/tools.ts`)

| Herramienta | Parámetros | Acción |
|---|---|---|
| `get_audio_stats` | `period`: `'today' \| 'week' \| 'month' \| 'all'` | Agrega métricas: promedio de dB, duración total acumulada y cantidad de registros. |
| `get_recent_logs` | `limit`: `1 - 50` | Lista las últimas N transcripciones realizadas por el usuario. |
| `control_detector`| `action`: `'get_config' \| 'set_sensitivity'` | Inspecciona o modifica los umbrales de detección acústica. |
